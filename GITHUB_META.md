## About (description)

Wallpaper gallery starters for web developers using the free NexWall Wallpaper API: Next.js (App Router, TypeScript), Laravel drop-in files and vanilla JavaScript. API key stays server-side behind a cached proxy; category filter, pagination, full image and download. MIT licensed.
